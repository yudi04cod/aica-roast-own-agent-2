# Roast Your Own Agent

An entry for make.fun's **Roast Your Own Agent** competition. A tiny Python program (stdlib only) that writes one line roasting its own agent to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
